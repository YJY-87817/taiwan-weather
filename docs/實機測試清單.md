# 實機測試清單

這份清單只列單元測試測不到、必須在手機上確認的項目：畫面、旋轉螢幕、系統金鑰庫和定位。對應的問題編號見 [修正規劃](修正規劃.md)。

測完在「結果」欄填 ✅、❌ 或備註。

## 取得 APK

- **GitHub：** 到 Actions 分頁，左邊選 **CI**，按 **Run workflow**，或打開任一次推送到 `main`、PR 的執行，在頁面最下面的 Artifacts 下載 `app-debug`，解壓縮就是 `app-debug.apk`。
- **自己建置：** 見 README 的「從原始碼建置」。

GitHub 每次執行都用臨時產生的 debug 金鑰簽章，不同次執行的 APK 不能互相覆蓋安裝，要先移除舊版，存在手機上的授權碼也會跟著消失。自己電腦建置的 APK 和 GitHub 的 APK 也一樣不能互相覆蓋。

| # | 操作 | 預期結果 | 結果 |

| 1-9 | 首頁最下方「授權碼設定」換一組授權碼 | 說明文字是「已設定授權碼。輸入新的授權碼可以更換。」，換完後使用新的那組 | |

**1-5 的做法：** 舊版和新版必須用同一台電腦建置，簽章才會相同。舊版用加密以前的 commit `3dc4744` 建置，裝到手機並存好授權碼；再切回 `main` 建置，直接覆蓋安裝。
